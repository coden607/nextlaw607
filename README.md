# NextLaw607

NextLaw607 is the first legal-intelligence application built on ContinuityOS.

Initial scope:
- New York criminal-law research and drafting
- source-first verified citations
- CourtListener / NY authority integrations
- legal-agent council and suppression analysis
- live encounter mode with de-escalation-first safety constraints
- offline rights pack

## Local development

```bash
continuity config-check continuity.toml
continuity execute "Explain the task" --config continuity.toml
```

ContinuityOS is maintained separately in `coden607/continuityos`.
